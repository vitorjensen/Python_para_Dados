# Análise de Preços e Margens

Este projeto automatiza a coleta de preços de mercado de combustíveis e calcula as margens de arbitragem frente aos custos industriais internos da companhia, servindo como ferramenta de análise de custos e suporte à decisão.

## Ferramentas
* **Python** (Pandas e NumPy para processamento de dados)
* **Playwright** (Web Scraping automatizado dos indicadores de mercado)
